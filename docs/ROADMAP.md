## After v1.0
- TOTP two-factor auth for Super Admin, Principal, Accountant, HR.
- Email and SMS delivery (DLT-compliant templates for India).
- Biometric attendance device integration (push API / CSV sync).
- Live GPS bus tracking and parent "bus is near" alerts.
- Hindi / regional language UI and public site.
- Installable PWA with offline attendance marking and sync.
- Statutory payroll (PF, ESI, Professional Tax, TDS, Form 16).
- Hostel management.
- Online admission applications by parents (public form → Admission DRAFT).
- Multi-branch / multi-tenant support (ADR-002 revisit).
- UDISE+ / board data export formats.
